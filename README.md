# 🐍 Snake Game

Welcome to the **Snake Game** — a fun classic built with **Python** and **Pygame**!  

This isn’t just a game — it’s a **learning project** designed to strengthen **Data Structures & Algorithms (DSA)** concepts through practical implementation.  

---

## 🎯 Learning Goal

The **main purpose** of building this game is to start learning **DSA by making projects**.  
By developing this Snake Game, you can understand and apply several **core programming and DSA topics**, such as:

### 🧩 DSA Concepts Covered
- **Arrays / Lists** → Managing the snake’s body segments (storing and updating positions).
- **Loops & Iteration** → Moving the snake continuously and updating its position frame by frame.
- **Conditional Logic** → Handling collision detection and direction control.
- **Randomization** → Generating random apple positions (like using random functions in algorithms).
- **Coordinate System & Grid Logic** → Understanding how 2D coordinates and grids work (used in many algorithmic problems).
- **Game Loop (Simulation Logic)** → Similar to iterative problem-solving or real-time algorithm updates.
- **Basic Object-Oriented Programming (OOP)** → Classes (`Game`, `Snake`, `Apple`) help you practice encapsulation and modular code design.

These concepts are the **foundation for more advanced DSA topics**, like queues, linked lists, and simulations — all of which you can explore by extending this project.

---

## 🕹️ Features
- Classic Snake gameplay: Eat apples to grow longer and increase your score.
- Smooth controls using the arrow keys.
- Random apple spawning.
- Real-time score display.

---

## 🧭 How to Play
1. **Start the game** by running the Python script.
2. **Control the snake** using arrow keys:
   - ⬆️ **Up Arrow** → Move Up  
   - ⬇️ **Down Arrow** → Move Down  
   - ⬅️ **Left Arrow** → Move Left  
   - ➡️ **Right Arrow** → Move Right  
3. **Goal:** Eat apples to grow the snake and increase your score.  
4. **Game Over:** If you hit the wall or your own body, the game ends.
