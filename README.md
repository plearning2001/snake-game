# Snake Game

Welcome to the **Snake Game**! 🐍

This is a simple snake game built with **Python** and **Pygame**. The objective is to control the snake, eat apples to grow longer, and avoid running into the walls or the snake’s own body.

## Features
- Classic Snake gameplay: Eat apples to grow longer and increase your score.
- Simple controls: Use arrow keys to control the snake.
- Random apple spawning: Apples appear at random positions on the screen.
- Score display: Shows the current score based on the number of apples eaten.

## How to Play
1. **Start the game**: Run the Python script to launch the game.
2. **Control the snake** using the arrow keys:
   - **Up Arrow**: Move Up
   - **Down Arrow**: Move Down
   - **Left Arrow**: Move Left
   - **Right Arrow**: Move Right
3. **Objective**: Eat as many apples as possible to grow the snake.
4. **Game Over**: The game ends if the snake collides with the wall or its own body.

- Python 3.x
